- Fixed a latent defect in `seam_blend.dart`: the composite loop blended best/second by distance but never read the ownership label, so pixels the cut assigned to the second frame still rendered the best frame's colour. Compositing is now owner-driven: alpha=1 on the owner's side of the seam, 0 on the other, cross-fade only within `kSeamFeatherPx = 5` px per side (band widens up to 3x toward the poles, intentional for polar seams).
