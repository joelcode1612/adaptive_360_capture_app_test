## 3DoF sphere: targets were tilted by the start pose
- Root cause: `_startDeviceToWorld` was seeded from the *raw* first rotation sample, so the phone's pitch/roll when Start was pressed was baked into the whole sphere. Measured: a 20 deg downward start put target 1 at -20 deg and the upper ring at 24.4 deg instead of 45 deg — a constant offset that still tracks correctly.
- Fix: `levelStartFrame()` in `sphere_target.dart` keeps the start heading and drops pitch/roll; controller uses it to seed `q0`. Near-vertical start falls back to the raw pose.
- Verified numerically in a standalone run; 4 regression tests added to `test/sphere_target_layout_test.dart`. `SPHERE_SENSOR` log now prints `start tilt removed=…°`.
